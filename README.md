# Gurgaon-Real-Estate-Market-Analysis

Project Overview

This project focuses on Exploratory Data Analysis (EDA) of the Gurgaon real estate market using Python.

The goal is to explore property-related data and understand patterns in property prices, locations, area, BHK configurations, property types, and builders.

Project Objectives

- Analyze real estate data from Gurgaon.
- Explore property prices and price per square foot.
- Understand locality-wise property information.
- Study different property types and BHK configurations.
- Explore property area and pricing patterns.
- Use data visualization to understand the dataset.

Dataset Information

The dataset contains 19,515 records and 12 columns.

Dataset file: "data.csv"

Dataset Columns

Column| Description
Price| Total property price
Status| Property construction status
Area| Property area
Rate per sqft| Price per square foot
Property Type| Property category
Locality| Property location
Builder Name| Builder information
RERA Approval| RERA approval status
BHK_Count| Number of bedrooms
Society| Society name
Company Name| Company or developer name
Flat Type| Type of flat

Technologies Used

- Python – Programming language
- Pandas – Data manipulation and analysis
- NumPy – Numerical operations
- Matplotlib – Data visualization
- Seaborn – Statistical data visualization

Installation and Setup

1. Clone the repository

git clone https://github.com/SoumiliKuila/Gurgaon-Real-Estate-Market-Analysis.git

2. Open the project folder

cd Gurgaon-Real-Estate-Market-Analysis

3. Install the required libraries

pip install -r requirements.txt

4. Run the Python file

python main.py
